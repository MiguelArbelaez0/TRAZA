# TRAZA

Plataforma para documentar trayectorias profesionales mediante experiencias,
competencias y evidencias verificables.

## Objetivo del MVP

- Gestionar un perfil profesional.
- Registrar experiencias laborales, prácticas y proyectos.
- Asociar competencias a experiencias.
- Adjuntar evidencias con controles de privacidad.
- Publicar un portafolio compartible.
- Crear y exportar un CV.
- Utilizar asistencia de IA sin inventar información profesional.

## Arquitectura prevista

- Frontend: React, Vite, TypeScript y Tailwind CSS.
- Backend: Python, FastAPI y Pydantic.
- Persistencia: PostgreSQL.
- Autenticación y almacenamiento: servicios de Supabase.
- Pruebas: Pytest y Playwright.
- Infraestructura: Docker Compose.
